# ライセンスと引用

project-owned code と独自に作成した schema transcription、文書、合成試験には、権利確認後に MIT を適用する方針です。DPC 元データ、公式マスタ、第三者資料、CaseCurator の private code まで MIT になるわけではありません。範囲は repository の `LICENSE` と `NOTICE.md` を確認してください。

公開版の引用情報は root の `CITATION.cff` に記載します。研究報告には実際に使用した package version に加え、schema ID、CCI 定義 ID・版・hash、および必要な原著・DPC 仕様を記録してください。

本ページは公開前の候補です。著者、公開 URL、release date、権利確認が確定した時点で citation と共に更新します。
