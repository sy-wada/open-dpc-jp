# ライセンスと引用

project-owned code と独自に作成した schema transcription、文書、合成試験には MIT を適用します。DPC 元データ、公式マスタ、第三者資料、CaseCurator の private code まで MIT になるわけではありません。範囲は repository の `LICENSE` と `NOTICE.md` を確認してください。

公開版の引用情報は root の `CITATION.cff` に記載します。研究報告には実際に使用した package version に加え、schema ID、CCI 定義 ID・版・hash、および必要な原著・DPC 仕様を記録してください。

著者、公開 URL、引用方法は repository の `CITATION.cff` を参照してください。公開日は実際の release に合わせて記載します。
