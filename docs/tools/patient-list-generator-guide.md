# 患者リスト作成ツール

[ブラウザ内の作成画面を開く](/tools/patient-list-generator/)

画面では CSV、表計算からのタブ区切り貼付、直接入力を使えます。取込時は列の割り当てを確認し、必要に応じて `research_id` を連番生成してください。エラーがある間はダウンロードを停止し、警告と自動変換を表示します。出力は [Patient List CSV 仕様](../specifications/patient-list.md)に従う UTF-8 BOM 付きです。

ツールはブラウザ内だけで処理し、患者データをサイトへ送信しません。入力は自動保存されません。共有端末では作業後にタブを閉じ、ダウンロード先のファイルを施設の運用規則に従って管理してください。
