# Open DPC JP

Open DPC JP は、日本の DPC FF1/EF データを読み取り、年度別の構造を明示して処理する Python ライブラリです。Charlson Comorbidity Index の版付き定義も提供します。初期公開版は Python API を中心とし、DPC 抽出 utility と患者リスト作成 Web ツールを別の補助機能として提供します。

このソフトウェアは DPC データの完全な提出検証器でも、臨床診断の確定手段でもありません。実データは利用施設の管理下に置いてください。
